تحديث رفيق الصلاة إلى النسخة 0.3.0

1) فك ضغط rafiq-salah-mobile-deploy-v3.zip على الهاتف.
2) افتح مستودع rafiq-salah في GitHub.
3) اختر Add file ثم Upload files.
4) ارفع محتويات الحزمة الجديدة كلها إلى جذر المستودع، ووافق على استبدال الملفات القديمة.
5) اضغط Commit changes.
6) انتظر اكتمال GitHub Pages، ثم افتح رابط التطبيق وأعد تحميله.

مهم: لا تحذف بيانات الموقع ولا تمسح بيانات Chrome. التحديث يستخدم مفتاح التخزين نفسه للمحافظة على سجل المستخدم المحلي. إذا لم يظهر التحديث فورًا، أغلق التطبيق المثبت وافتحه مجددًا ثم حدّث الصفحة.
